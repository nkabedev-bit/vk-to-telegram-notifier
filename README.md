# Уведомления из сообществ ВК в Telegram

Бот присылает в Telegram каждое входящее сообщение из сообществ ВК:

```
Название сообщества: …

Имя Фамилия: …

Текст сообщения: …

Ссылка на диалог: …
```

В ВК он ничего не отвечает, сообщения прочитанными не помечает и настройки сообществ не меняет.
Зависимостей нет, нужен только Python 3.8+.

## Перед первым запуском

1. Получатель (id из `telegram_chat_id`) открывает бота в Telegram и нажимает «Старт».
   Без этого Telegram не даст боту написать первым.
2. Проверьте настройки (команда ничего не отправляет):

   ```bash
   python3 bot.py --check
   ```

   Все сообщества должны быть «готово», а получатель — «бот может ему писать».

## Запуск

```bash
python3 bot.py
```

Бот работает, пока открыт терминал и компьютер не спит. Для работы круглосуточно запустите его на сервере.

## На этом Mac (уже настроено)

Бот запускается сам при входе в систему и перезапускается при сбое
(`~/Library/LaunchAgents/com.kabedev.vk2tg.plist`). Пока Mac на зарядке, он не засыпает;
на батарее и с закрытой крышкой Mac спит как обычно, и бот в это время не работает.
Лог: `bot.log` в этой папке. Не запускайте `python3 bot.py` вручную параллельно — уведомления задвоятся.

Перезапустить (например, после правки `config.json`):

```bash
launchctl kickstart -k gui/$(id -u)/com.kabedev.vk2tg
```

Остановить и убрать из автозапуска:

```bash
launchctl bootout gui/$(id -u)/com.kabedev.vk2tg && rm ~/Library/LaunchAgents/com.kabedev.vk2tg.plist
```

## На хостинге bothost.ru

Нужен платный тариф (Basic): на бесплатном нельзя задать переменные окружения и выбрать локацию.
Локация — **Нидерланды**: из России Telegram API заблокирован.

- Bot Token — токен Telegram-бота (попадёт в бота как `BOT_TOKEN`).
- Переменные окружения — «Загрузить из файла .env», файл `bothost.env` (лежит только локально, в git не попадает):
  `TELEGRAM_CHAT_ID` и `VK_COMMUNITY_TOKENS` (токены сообществ через запятую).
- Главный файл — `bot.py`. Домен и собственный Dockerfile не нужны.

Если переменные окружения заданы, `config.json` не используется.

## Круглосуточно на Linux-сервере (systemd)

Скопируйте `bot.py` и `config.json` в `/opt/vk2tg`, создайте `/etc/systemd/system/vk2tg.service`:

```ini
[Unit]
Description=VK -> Telegram notifications
After=network-online.target
Wants=network-online.target

[Service]
WorkingDirectory=/opt/vk2tg
ExecStart=/usr/bin/python3 /opt/vk2tg/bot.py
Restart=always
RestartSec=10

[Install]
WantedBy=multi-user.target
```

```bash
sudo systemctl enable --now vk2tg
```

```bash
journalctl -u vk2tg -f
```

## Добавить или убрать сообщество

В сообществе: Управление → Работа с API → Ключи доступа → создать ключ с правом «Сообщения сообщества».
Добавьте ключ в список `vk_community_tokens` в `config.json` и перезапустите бота.

## Ограничения

- Сообщения, пришедшие, пока бот был выключен, не пересылаются.
- Если в сообщении только вложение (фото, стикер, голосовое), строка «Текст сообщения» будет пустой.
